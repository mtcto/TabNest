TabNest 0.1.0 is not Authenticode-signed.

Windows SmartScreen may show "Windows protected your PC".
Click More info, confirm the file name, then Run anyway.

Antivirus products may quarantine an unsigned window manager.
Restore it only if you obtained this installer from the official
TabNest GitHub repository.

A signed official binary is not provided.
If you need a signed build, purchase an OV code-signing certificate
yourself and sign TabNest.exe plus this setup package.
